# hello-world

Una paginetta statica per testare il workflow su Bitbucket.

## Come provarla in locale

Apri direttamente `index.html` nel browser, oppure servila con un piccolo server:

```bash
python3 -m http.server 8080
# poi vai su http://localhost:8080
```

## Stack

HTML + CSS puro, zero dipendenze. Font caricati da Google Fonts (JetBrains Mono + Fraunces).
